\# Task 6: Host a Static Website Using GitHub Pages

    

\## Project Overview

The objective of this project is to create and host a static portfolio website using GitHub Pages. The website presents my professional profile, technical skills, projects, certifications, and contact information.
 
 ## 🌐 Live Demo

**Visit my deployed portfolio website:**

👉 https://harshgithello.github.io/portfolio/

## 📂 GitHub Repository

Source code: https://github.com/harshgithello/portfolio


\## Technologies Used

\- HTML5 – To structure the website.

\- CSS3 – To style the website and create a responsive layout.

\- Git – For version control.

\- GitHub – To store and manage the project repository.

\- GitHub Pages – To host and publish the static website.

\- GitHub Actions – To automate the deployment process.



\## Project Features

\- Professional portfolio homepage.

\- About Me section.

\- Technical skills section.

\- Projects showcase.

\- Certifications section.

\- Contact information and profile links.

\- Responsive design for different screen sizes.
